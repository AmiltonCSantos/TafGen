Como executar o sistema:<br>
Você deve fazer a clonagem do repositorio.<br>
na pasta TafGen/TafGen deve se executar o servidor<br>
npx json-server --watch db.json --port 3001<br>
ainda na mesma pasta deve se iniciar o sistema<br>
executando <br>
npm install<br>
e logo em seguida<br>
npm start<br>
a aplicação deve abrir em um endereço local, normalmente no http://localhost:3000.<br><br>

Tecnologias utilizadas :<br>
SweerAlert 2 - Ferramentas para criação de alertas mais atuais, sem precisar de utilização dos alertas do windows.<br>
link: https://sweetalert2.github.io/#examples<br><br>

React Router Dom - utilizado para troca de paginas vias routes e link, facilitando a troca das paginas.<br>
link: https://reactrouter.com/<br><br>

React Hook Form - Utilizado para a criação do formulario, facilita a coleta de informações de formulario para entregar ao banco.<br>
link: https://react-hook-form.com/<br><br>

Css3Nativo - Para estilização das paginas.<br>
Json server - Para criar um banco de dados local.<br><br>
