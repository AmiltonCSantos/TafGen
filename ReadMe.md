Como executar o sistema:
Você deve fazer a clonagem do repositorio.
na pasta TafGen/TafGen deve se executar o servidor
npx json-server --watch db.json --port 3001
ainda na mesma pasta deve se iniciar o sistema
executando 
npm install
e logo em seguida
npm start
a aplicação deve abrir em um endereço local, normalmente no http://localhost:3000.

Tecnologias utilizadas :
SweerAlert 2 - Ferramentas para criação de alertas mais atuais, sem precisar de utilização dos alertas do windows.
link: https://sweetalert2.github.io/#examples

React Router Dom - utilizado para troca de paginas vias routes e link, facilitando a troca das paginas.
link: https://reactrouter.com/

React Hook Form - Utilizado para a criação do formulario, facilita a coleta de informações de formulario para entregar ao banco.
link: https://react-hook-form.com/

Css3Nativo - Para estilização das paginas.
Json server - Para criar um banco de dados local.
